# Mox homepage (G2)

Standalone copy of the approved G2 prototype, published with GitHub Pages at
https://0x4e4d.github.io/mox/ by `.github/workflows/pages.yml` on every push to `main` that touches `site/`.

Source of truth for the design is `prototypes/g2.html` on the prototypes branch; this folder is that page
without the "All versions" button, plus only the images it uses.
